## 我是谁

你好，我是一个普通的开发者，白天写业务代码，晚上写点没什么用但自己想写的东西。

这个网站用来放三类内容：技术笔记、读书笔记、以及一些放在社交平台上显得太长的生活碎片。

## 关于这个站

- **内容**：全部是 Markdown 文件，存在一个 Git 仓库里；
- **生成**：一个不到五百行、零依赖的 Node 脚本；
- **托管**：Cloudflare Pages；
- **域名**：DigitalPlat 的免费二级域名，NS 托管在 Cloudflare。

没有数据库，没有后台，没有登录，也没有统计你停留了多久的脚本。

> 我希望它像一间安静的书房：推门进来，能看清字，就够了。

## 关于写作

我写字很慢，通常一篇要改三遍以上。也不太追时效——过三个月还值得看的东西，才值得写下来。

如果某篇文章里有一句话帮到了你，那这篇就没白写。
