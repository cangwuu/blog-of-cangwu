## 标题

一到六级标题都支持，`##` 和 `###` 会自动出现在右侧目录里。

### 这是一个三级标题

#### 这是一个四级标题

## 文字样式

**加粗**、*斜体*、~~删除线~~、`行内代码`、==高亮==。

链接写成 [Cloudflare Pages](https://pages.cloudflare.com)，会自动在新标签页打开。

## 列表

无序列表：

- 第一项
- 第二项
  - 嵌套一层
  - 再嵌套一层
- 第三项

有序列表：

1. 先做这个
2. 再做那个
3. 最后收尾

## 代码

行内代码像这样：`const x = 1`。

带语言标记的代码块：

```js
export function greet(name) {
  const hour = new Date().getHours();
  const when = hour < 6 ? '凌晨' : hour < 12 ? '早上' : '下午';
  return `${when}好，${name}`;
}
```

```bash
node build.mjs && node serve.mjs
```

## 表格

| 语法 | 说明 | 支持 |
| --- | :---: | ---: |
| `**粗体**` | 加粗 | 是 |
| `~~删除~~` | 删除线 | 是 |
| `==高亮==` | 标记 | 是 |

## 提示

写文章的时候不用管排版，生成器会处理段落间距、代码高亮框和目录。

但有两件事它不会替你做好：

1. 段落之间记得空行；
2. 图片记得写 `alt`。
